# DSA Interview Prep (JavaScript)

📅 Daily Goal: 1 hour  
🛠 Language: JavaScript (Node.js)  
🎯 Target: Master DSA from scratch and transition

---

## 📅 Rough 9-Week DSA Plan

| Week | Data Structure   | Implementation Tasks                   | Related Problems                     |
|------|------------------|----------------------------------------|--------------------------------------|
| 1    | Arrays & Strings | Push, Pop, Slice, Reverse, Join        | Two Sum, Move Zeroes, Anagram        |
| 2    | Linked List      | Singly & Doubly, Reverse, Cycle        | Middle of LL, Detect Cycle           |
| 3    | Stack & Queue    | Array-based, Linked List-based         | Valid Parentheses, Min Stack         |
| 4    | HashMap & Set    | Build from scratch using array/buckets | Two Sum, Group Anagrams              |
| 5    | Tree (BT, BST)   | Traversals, Insert/Delete/Search       | Inorder, Level Order, Symmetric Tree |
| 6    | Heap             | Min/Max Heap, Heapify, Priority Queue  | K Largest, Merge K Lists             |
| 7    | Graph            | Adjacency List/Matrix, DFS/BFS         | Clone Graph, Number of Islands       |
| 8    | Trie             | Insert, Search, Prefix                 | Word Search II, Prefix Matching      |
| 9    | DP Table         | Fib, Knapsack, LIS                     | Classic DP problems                  |
